# Registro de acesso do Traefik em arquivo: lista de flags, sem contexto, para acrescentar ao `command:` do serviço do
# Traefik (mantenha --accesslog=true e --accesslog.format=json). Passo a passo: docs/runbook/log-retention.md.
# Tudo o que não está na lista de "keep" é descartado (defaultmode=drop), inclusive o caminho com a query (RequestPath) e os
# cabeçalhos. O IP do visitante é o cabeçalho Cf-Connecting-Ip; ClientAddr é o par TCP (a borda da Cloudflare). ClientHost fica
# FORA de propósito: o Traefik o troca pelo X-Forwarded-For inteiro, que o visitante consegue preencher. Não use flags de versões novas do Traefik aqui (ex.: queryparameters): flag desconhecida impede o proxy de subir.
--accesslog.filepath=/var/log/traefik/access.log
--accesslog.fields.defaultmode=drop
--accesslog.fields.names.StartUTC=keep
--accesslog.fields.names.ClientAddr=keep
--accesslog.fields.names.RequestHost=keep
--accesslog.fields.names.RequestMethod=keep
--accesslog.fields.names.DownstreamStatus=keep
--accesslog.fields.names.RouterName=keep
--accesslog.fields.headers.defaultmode=drop
--accesslog.fields.headers.names.Cf-Connecting-Ip=keep

# Volume do mesmo serviço (pasta do host criada antes, ver o runbook):
/var/log/traefik:/var/log/traefik
